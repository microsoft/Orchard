# Examples — Orchard-GUI

This folder will host runnable examples for the **Orchard-GUI** recipe — the
SFT and on-policy RL training pipelines that produced the **68.4%** average
(WebVoyager / Online-Mind2Web / DeepShop) result with Qwen3-VL-4B-Thinking on
the Orchard-GUI trajectory data.
